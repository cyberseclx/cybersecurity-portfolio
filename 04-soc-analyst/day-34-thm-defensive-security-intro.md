## Tasks Completed

### Task 1 - Think like a Defender

The room began by shifting the focus from attacking systems to protecting them.

Key defensive mindset:

- Observe what is happening
- Look for activity that does not appear normal
- Review available evidence
- Take action based on what is found

### Task 2 - Detect Suspicious Activity

This task focused on recognizing activity that may indicate an ongoing attack.

A defender must first notice abnormal or suspicious behaviour before the event can be investigated.

### Task 3 - Identify the Attack

After detecting suspicious activity, the next step is to determine what attack is taking place.

```text
Suspicious activity detected
        ↓
Evidence reviewed
        ↓
Attack identified
```

### Task 4 - Stop the Attack

The final task focused on taking action to stop the ongoing attack against FakeBank.

```text
Detection → Identification → Response
```

## Defensive Security Workflow

1. Think from the defender's perspective.
2. Monitor for suspicious activity.
3. Identify the attack using available evidence.
4. Take action to stop the attack.

## Practical Relevance

This room introduced the basic mindset required for defensive security work:

- Protecting systems and users
- Detecting unusual activity
- Investigating what happened
- Responding to an active threat

## Key Takeaways

- Defensive security focuses on protecting systems from attacks.
- Suspicious activity must be detected before it can be investigated.
- Detection alone is not enough; the attack must also be identified.
- The defender's final objective is to stop or contain the attack.
- A basic defensive workflow is detection, identification, and response.
